# ✨ Обновления Ssoly UI

## Что добавлено:

### 1. 🎨 Система частиц (переключаемая)
- Красивые анимированные частицы на фоне UI
- Можно включать/выключать в настройках
- Не влияет на производительность

**Как использовать:**
```lua
-- В настройках добавлен переключатель
SettingsTab:AddToggle({
    Title = "Particles Effect",
    Description = "Enable/disable animated particles",
    Default = true,
    Callback = function(Value)
        Window:SetParticlesEnabled(Value)
    end
})
```

### 2. 🎭 Красивые иконки с анимациями
Добавлены плавные анимации как в maclib:

**В Dropdown:**
- ▼ Стрелка плавно вращается при открытии
- ✓ Чекмарки появляются с bounce эффектом
- Цвета плавно меняются при наведении
- Все анимации синхронизированы с accent color

**Примеры анимаций:**
- Hover эффекты (изменение прозрачности)
- Rotation (вращение стрелок)
- Scale (увеличение/уменьшение)
- Fade (плавное появление/исчезновение)
- Pulse (пульсация)
- Color transitions (цветовые переходы)

## Как это выглядит:

### Dropdown:
1. При наведении - стрелка светлеет
2. При открытии - стрелка вращается на 180° с bounce эффектом и меняет цвет на accent
3. При выборе опции - чекмарк появляется с плавной анимацией
4. При закрытии - все возвращается обратно плавно

### Частицы:
- Маленькие светящиеся точки плавно двигаются по экрану
- Можно выключить в настройках если мешают
- Не нагружают игру
